# Visualizações de embeddings

20 pares de perguntas individuais e 20 pares de conjuntos de palavras-chave, selecionados por similaridade cosseno.

O arquivo index.html é independente: incorpora os 40 gráficos SVG, ranking CSV, navegação por categoria, busca e filtro Luna.

Esta branch contém exclusivamente os arquivos estáticos de publicação; o código do projeto permanece na branch principal.
